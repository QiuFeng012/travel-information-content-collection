# assets/photos/

地点图片放这里。**这个目录现在只有说明，还没有任何图片。**

## 怎么用

1. 把图片拷进这个目录，文件名建议用「地点 id + 序号」，例如
   `gd-museum-1.jpg`、`xiaocang-canteen-1.jpg`。id 就是 `data/places.js`
   里每个地点的 `id` 字段。
2. 在该地点的数据里加一个 `photos` 数组，路径从仓库根目录算起：

```js
{
  id: 'gd-museum',
  name: '广东省博物馆',
  // …
  photos: ['assets/photos/gd-museum-1.jpg', 'assets/photos/gd-museum-2.jpg']
}
```

3. 跑一下 `node tools/check-data.mjs`——它会检查每个路径是不是真的存在。

不写 `photos` 或写成 `[]` 都表示这个地点还没有图，详情页不会显示图片区。

## 也可以不碰文件

网页的**编辑模式**里能直接加图：

- 「＋」从本机选图——会先压到最长边 1280px 再存进浏览器，原图不动。
  方便，但**这类图只活在当前这台设备的这个浏览器里**，换设备或清缓存就没了。
- 粘贴图片链接（`https://…` 或 `assets/photos/xxx.jpg`）。

两种方式在页面上看不出区别，区别只在于能不能跟着 `places.js` 走。想长期保留，
就走上面的「拷文件 + 写路径」。

## 体积

图片进仓库会永久留在 git 历史里，删掉也还是在。建议：

- 单张压到 **300 KB 以内**，最长边 1600px 足够在手机上看
- 一次别加太多张，`data/places.js` 和仓库都会变重
- 网页离线缓存会把看过的图一并存下来，图太多会撑爆浏览器配额
